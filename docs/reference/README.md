# Reference material for the §12.2 blind-A/B bars

GDD §12.2 grades several pieces by blind comparison against real reference:
16-bit sprite work, federation result sheets, and meet footage. Image hosts are
refused by this sandbox's egress policy, so a critic cannot fetch any of that
itself. Reference has to be committed here.

Drop files in this directory and a critic can open them with the Read tool,
which displays images. Name them by what they are evidence *for*:

| filename pattern | grades |
|---|---|
| `sprite-ref-*.png` | Lifter sprites & animation (§12.2 row 1), gym/environment art (row 2) |
| `scoresheet-ref-*.png` | Result card (row 4) — the organic-growth lever |
| `meet-photo-ref-*.png` | Meet-day tension (row 3), and body position for sprite work |

A critic that cannot find a reference for its bar reports that half of the bar
**unverifiable** rather than passing it on reasoning — see CLAUDE.md. Adding a
file here is what converts an unverifiable bar into a gradeable one, so it is
worth being deliberate about what each file is meant to prove.

Do not put approximations or redrawings here. A generated stand-in for a real
SNES sprite is worse than no reference: it would let a critic report a pass
against something this project made up.
